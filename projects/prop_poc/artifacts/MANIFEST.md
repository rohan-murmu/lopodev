# prop_poc artifact manifest

Tracked evidence for the proof-of-concept vertical slice:

- `qa_report.json` - gate results with commands and evidence paths.
- `screenshots/main_scene.png` - inspected graphical screenshot.
- `sm_crate.validate.json` - GLB validation report.
- `sm_gem.animation.json` - animation channel report.
- `spec_validation.json` - project spec validation result.

`logs/` and `previews/` are regenerated by the pipeline on every run and are
gitignored. Reproduce them with `tools/run_poc.sh`; do not edit generated logs or
previews by hand.
