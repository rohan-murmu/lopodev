# Game Brief
Title: Green Hell
Pitch: Fight through a jungle held by mercenaries to reach the extraction radio.
Genre: first-person shooter
Art style: stylized
Theme/setting: tropical jungle with ancient ruins
Camera: first-person
Core loop: move through cover -> spot enemies -> shoot -> collect ammo -> push to the next clearing
Win: reach the radio and call extraction
Lose: health reaches zero
Platform: android
Orientation: landscape
Controls: virtual joystick + look + buttons
Actions: shoot, reload, crouch
World: jungle, ruins
World size: large
Characters:
- mercenary (enemy, idle/walk/run/shoot/hit/death)
Must-have assets: rifle, ammo crate, radio
Screens: main menu, level select, HUD, pause, game over, win
